# Camp des Maraudeurs Ferrailleurs (Jawas)

Niché dans l'ombre fraîche du Grand Canyon, ce campement troglodyte est le repaire d'une communauté de ferrailleurs Jawas. Spécialisés dans le démantèlement d'épaves de navettes et le recyclage de processeurs droïdes, ils pratiquent le troc direct sans passer par les crédits standard.

## Résident Notable
- **Klik'Tik** (`ferrailleur_kliktik`) : Chef troqueur Jawa au cri légendaire (*« Utini ! »*), passionné par les circuits intégrés et les servos magnétiques.

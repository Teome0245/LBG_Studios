# Ferme d'Humidité Lars-Val

Implantée au centre des étendues arides de [[scrapaltai]], cette exploitation semi-enterrée compte 24 vaporisateurs atmosphériques captant la rosée nocturne. L'eau potable collectée ici est une ressource vitale acheminée vers les cités et convoitée par les pillards.

## Résident Notable
- **Valen Lars** (`fermier_valen`) : Fermier d'humidité veillant sur les filtres et les réservoirs le blaster armé.

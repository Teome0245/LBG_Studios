# Les Chantiers Navals Orbitaux

Basés sur [[terre_one]], les **Chantiers Navals Orbitaux** représentent la corporation industrielle majeure fabriquant les chasseurs spatiaux, les shuttles et les hyper-drives.

## Activités & Rôle Économique
- Production de masse de blindages et de générateurs pour le [[craft_artisanat]].
- Formation des pilotes de ligne spatiale en tandem avec l'instructeur [[garr_vek]].
- Achats réguliers d'alliages recyclés auprès du [[syndicat_ferrailleurs]] de [[scrapaltai]].

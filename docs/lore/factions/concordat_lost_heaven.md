# Le Concordat de Lost Heaven

Le **Concordat de Lost Heaven** est l'autorité démocratique et administrative régissant la métropole de Lost Heaven sur [[scrapaltai]].

## Gouvernance & Politique
- Régie par le système de [[villes_politique]] : les citoyens votent périodiquement pour élire le Maire.
- Le Maire vote les décrets municipaux (zones franches industrielles, sanctuaires médicaux, taxes foncières).
- Maintient la paix entre les arrivants et prévient les abus monopolistiques du [[syndicat_ferrailleurs]].

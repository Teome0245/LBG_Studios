# Klik'Tik — Chef Troqueur Jawa

Figure emblématique du [[camp_ferrailleurs]] dans le Grand Canyon. Klik'Tik refuse les crédits galactiques pour privilégier le troc de pièces technologiques rares : puces mécatroniques, noyaux d'astromécanos et injecteurs révisés.

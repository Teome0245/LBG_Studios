# Varkoon — Le Pisteur des Canyons

Varkoon est un chasseur Wookiee aguerri qui a élu domicile dans les confins sauvages de [[scrapaltai]]. Équipé d'une arbalète lourde et connaissant chaque tanière de prédateurs, il entraîne les jeunes aventuriers aux techniques de traque.

## Relations & Interactions
- Guide les expéditions de prélèvement d'échantillons génétiques pour la [[bio_ingenierie]].
- Alliée de [[fel_rani]] pour sécuriser les routes caravanières de [[concordat_lost_heaven]].
- Méprise les méthodes destructrices du [[syndicat_ferrailleurs]].
